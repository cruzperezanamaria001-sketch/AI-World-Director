# Local Bridge Protocol — Draft v0

## Transport

- HTTP bound to 127.0.0.1 only.
- JSON request and response bodies.
- Authentication header: Authorization: Bearer <secret>.
- The secret is generated by the mod and stored outside the repository.
- No public port forwarding.

## Initial endpoints

- GET /health — bridge readiness and protocol version.
- GET /v1/world — world snapshot.
- GET /v1/player — player status.
- GET /v1/events?after=<cursor> — recent event batch.
- GET /v1/actions — recent action history.
- POST /v1/actions — submit one director action.

## Action envelope

```json
{
  "action_id": "client-generated-uuid",
  "type": "spawn_entity",
  "payload": {
    "entity": "minecraft:zombie",
    "count": 2,
    "radius": 8
  }
}
```

The server response must distinguish accepted, rejected, queued, executed, and failed. The MCP tool must not report success merely because the HTTP request was accepted.

## Initial action types

- spawn_entity — allowlisted entity IDs and bounded count.
- give_item — allowlisted item IDs and bounded quantity.
- set_time — day/night or a validated numeric time.
- set_weather — clear/rain/thunder with bounded duration.
- create_event — a small composition of individually validated actions.

Every request is authenticated, schema-validated, rate-limited, deduplicated, and audited.
