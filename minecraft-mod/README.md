# Minecraft Forge Mod

Target: Minecraft 1.20.1, Forge 47.4.10, Java 17.

This directory will contain the Forge MDK project. The first implementation milestone is:
1. Register the mod.
2. Add a server-side health/status endpoint bound to localhost.
3. Observe player login, death, damage, kills, item pickup, and dimension changes.
4. Return world/player snapshots.
5. Add validated action execution on the server thread.

The Gradle wrapper and Forge MDK build files will be committed with the first compilable mod milestone.
